# Intro fonts

These fonts are served locally and used only within `.intro`.

- Jeju Hallasan Regular: https://github.com/google/fonts/tree/main/ofl/jejuhallasan
- Julius Sans One Regular: https://github.com/google/fonts/tree/main/ofl/juliussansone

Both fonts use the SIL Open Font License; their original license notices are included here. Jeju Hallasan retains its original Korean and Latin character coverage.
